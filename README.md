# Breast Cancer Prediction using Keras

A deep learning-based **binary classification project** for predicting breast cancer diagnosis using an Artificial Neural Network (ANN) built with **TensorFlow and Keras**.

##  Project Overview

The objective of this project is to build a machine learning model that can classify breast cancer cases based on the available diagnostic features in the dataset.

The project covers the complete machine learning workflow:

* Data loading and preprocessing
* Exploratory data analysis
* Feature scaling
* Train-test splitting
* Artificial Neural Network development
* Model training and validation
* Model evaluation
* Prediction on new data
* Visualization of model performance

##  Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Scikit-learn**
* **TensorFlow**
* **Keras**

## 🤖 Model

An **Artificial Neural Network (ANN)** is implemented using TensorFlow/Keras for binary classification.

The workflow includes:

```text
Dataset
   ↓
Data Preprocessing
   ↓
Feature Scaling
   ↓
Train / Test Split
   ↓
ANN Model
   ↓
Model Training
   ↓
Evaluation
   ↓
Breast Cancer Prediction
```

## 📊 Model Evaluation

The model is evaluated using classification metrics including:

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC
* Confusion Matrix

Training and validation performance are also visualized to understand the model's learning behavior.
